=============================================================
   ALTA DE CLIENTES - Sistema SeS  (uso privado del dueño)
=============================================================

¿PARA QUÉ SIRVE?
Para dar de alta un negocio (cliente) nuevo en segundos.
Crea automáticamente:
  - El negocio (tenant)
  - El usuario administrador del cliente (correo + contraseña)
  - La configuración inicial (moneda del país, etc.)

Cada cliente entra al MISMO sitio web pero ve SOLO su negocio.

CONFIGURACIÓN SEGURA OBLIGATORIA
-----------------------------------------------------------
Los scripts ya NO guardan una clave privilegiada dentro del código.

Antes de usarlos, configura en Windows la NUEVA clave rotada como
variable de entorno del usuario:

  setx SUPABASE_SERVICE_KEY "PEGA_AQUI_LA_NUEVA_CLAVE"

Después CIERRA esa ventana de CMD y abre una nueva. La variable
SUPABASE_SERVICE_KEY no debe copiarse a GitHub, archivos .py, .bat,
capturas ni mensajes.

Opcionalmente puedes configurar SUPABASE_URL si alguna vez cambias
de proyecto. Si no existe, se usa el proyecto actual.

CÓMO USARLO (en tu PC con Windows)
-----------------------------------------------------------
1) Asegúrate de tener Python instalado.
2) Configura SUPABASE_SERVICE_KEY como se indicó arriba.
3) Haz doble clic en "Crear Cliente.bat".
4) Completa nombre del negocio, correo, contraseña y país/moneda.

CÓMO CREAR UN EMPLEADO O SUPERVISOR
-----------------------------------------------------------
1) Doble clic en "Crear Empleado.bat".
2) Elige el negocio.
3) Pon nombre, correo, contraseña y rol.
4) Entrega los datos de acceso al empleado.

IMPORTANTE - SEGURIDAD
-----------------------------------------------------------
- Una clave service/secret de Supabase tiene privilegios elevados.
- Si alguna clave fue publicada en GitHub, trátala como comprometida:
  primero elimina su uso del código y luego rótala/revócala.
- No guardes claves nuevas dentro del repositorio.
- Los scripts fallan de forma segura si SUPABASE_SERVICE_KEY no existe.
